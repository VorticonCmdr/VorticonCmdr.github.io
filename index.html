The workbench

The tools the ports are dug out with: a scriptable DOSBox debugger and Ghidra, both connected to AI agents over MCP. These are forks, with my additions on top.

  • dosbox-mcp The DOSBox MCP server, with the debugger tools wired up. fork of dosbox-automation
  • dosbox-automation DOSBox with a headless debugger automation API. fork of dosbox-automation
  • ghidra-mcp A Ghidra MCP server with 200+ tools for AI-assisted reverse engineering, as a GUI plugin or headless server. fork
